This week's sprint

Engineer levels

Real software companies level their engineers L1 to L7. You climb by earning points, and you never drop a level. In the real world, L1 engineers average about $108K a year and L7s about $395K.

Activities

Only activities where you write code and get a green circle earn points. Each one counts once. Stuck? Check who already shipped it and ask them. Helpers earn Mentor points.

How to commit

Commit means turning your work in to the sprint. Points land on the Build Dashboard in about 30 seconds.

Turn it in on TechSmart

Get the green "Turned In" badge in the top right.

Grab your proof

Screenshot the top of the page: your name in the top right, the activity name, and the green "Turned In" badge, all in one shot.

Press Commit

Use the Commit button on that activity's card. The form opens with the activity already picked.

Name your helper

Did a classmate help you? Pick their name in the form. They earn Mentor points.

Proof that counts

Your name, the activity name, and the green badge must all show. Any green circle passes, full or partial. An empty circle means no code was written, and that commit gets flipped to Needs Work. Code Your Own is different: upload your code as a PDF or .py file.

Team rules

Helping is hands off the keyboard. Explain and point, never type on someone else's laptop. Use the same laptop and browser every class so this page remembers you.
