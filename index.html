This week's sprint

Engineer levels

Real software companies level their engineers L1 to L7. You climb by earning points, and you never drop a level. In the real world, L1 engineers average about $108K a year and L7s about $395K.

Quests

Every TechSmart activity where you write code is a quest. Finish it, commit it, and it's shipped. Each one counts once. Stuck? Check who already shipped it and ask them. Helpers earn Mentor points.

How to commit

Commit means shipping your work to the sprint. Your code gets checked in seconds, and points land on the Build Dashboard right away.

Turn it in on TechSmart

Finish the activity and turn it in like always.

Download your Project

In TechSmart, click Download, then Project. You get a .zip file. Don't open it, just keep it.

Press Ship it

Use the Ship it button on that quest. Your heron's page opens with the quest already picked. Upload the zip.

Name your helper

Did a classmate help you? Pick their name before you ship. They earn Mentor points.

How your code is checked

Every TechSmart activity is a list of tasks. Ship it counts how many tasks have your code under them. Under a quarter done comes back as Needs Work: finish more and ship again. Three quarters or more, using the right pieces, is a Clean build with better drop odds. It has to be your own Project zip for the quest you pick. Read the code quests still use the Commit form with a screenshot.

Team rules

Helping is hands off the keyboard. Explain and point, never type on someone else's laptop. Use the same laptop and browser every class so this page remembers you.
